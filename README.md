# Vulno42 – Manual Software Testing

## About the Project

Vulno42 is an interactive cybersecurity web platform developed as a final project for the **42 Advanced Digital Skills Program – Cybersecurity Track**.

The platform provides hands-on learning experiences through interactive web security labs covering common vulnerabilities, attack simulations, and security fixes.

This repository documents my Quality Assurance (QA) contributions to the project, focusing on manual testing, identifying issues, and verifying application functionality and user experience.


## My Role – Quality Assurance Engineer

Responsible for performing manual testing to evaluate the platform's functionality, usability, and content accuracy.


## Testing Scope

- Functional Testing
- UI Testing
- Content Validation
- Test Case Design and Execution
- Bug Identification and Reporting
- Usability and User Experience Review

## Security Labs Tested

1. **DOM-Based Open Redirect**
2. **Regular Expression Denial of Service (ReDoS)**
3. **Client-Side Prototype Pollution**

## Testing Deliverables

- Manual Test Cases
- Bug Reports with Steps to Reproduce
- Actual and Expected Results
- Bug Severity and Priority
- Screenshots and Testing Evidence
- Testing Documentation

## Tools Used

- Microsoft Excel – Test Case Design and Bug Reporting
- GitHub – Project Files and Documentation
- Web Browser – Application Testing
